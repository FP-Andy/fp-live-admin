영상 등록부터 작업 화면까지

  1. 영상 트래킹에서 원본 영상을 선택합니다. FPC에서는 여러 파일을 선택하면 S3에 차례로 업로드합니다. 업로드가 끝날 때까지 브라우저와 컴퓨터를 켜두세요. 완료한 영상은 창을 다시 열어도 업로드된 영상에 남습니다. 각 영상의 초기 설정을 눌러 설정을 시작합니다. 같은 창에서 올린 영상은 내 컴퓨터의 원본으로 바로 미리봅니다. 창을 다시 열었다면 내 컴퓨터 원본으로 미리보기에서 같은 파일을 연결할 수 있으며, 재업로드하지 않습니다. 로컬 미리보기에서는 현재 컴퓨터에서 처리합니다. 상단의 실행 환경을 확인하세요. 브라우저가 원본 형식을 재생하지 못하면 원본에서 장면 이미지를 추출합니다. 이 경우 장면 시각 (초)로 원하는 시점을 선택하세요.
  2. 경기장 선을 따라 네 꼭짓점을 순서대로 찍습니다. 네 점은 드래그로 조정할 수 있습니다. 실제 코트 선에 맞추세요. 터치라인 밖 추적 여유는 별도로 적용되므로 코트를 일부러 넓게 지정할 필요가 없습니다.
  3. 13명이 잘 보이는 장면을 고르고 이 장면에서 선수 찾기를 누릅니다. 전체 분석 전에 이 한 장면만 검출합니다. S3 원본 전체를 내려받지 않고 선택한 장면에 필요한 구간만 읽습니다. 원본의 장면 이미지 위에 선수 박스가 표시됩니다.
  4. 아래 유니폼 5그룹에서 각 스포이드로 유니폼을 찍습니다. 박스를 클릭하면 확대 화면에서도 색상을 찍을 수 있습니다. 그림자·무늬에 맞춰 그룹마다 여러 색상을 추가할 수 있습니다.
  5. 중복이나 그림자가 포함된 BB는 영상 또는 BB 선택 목록에서 고른 뒤 선택 BB 제외를 누릅니다. 최근 제외 복원으로 되돌리거나, 제외 BB 표시를 켜고 해당 BB를 선택한 뒤 선택 BB 복원을 누르세요. 제외한 BB의 선수 연결은 풀리며 등번호는 유지됩니다.
  6. 초기 13명에 등번호를 입력하고 박스 연결 → 해당 영상 박스를 클릭합니다. 홈 키퍼 1명·홈 5명·심판 1명·어웨이 5명·어웨이 키퍼 1명을 연결합니다. 같은 팀 등번호 중복과 한 박스의 중복 지정은 허용하지 않습니다. 선수가 가려졌다면 다른 장면 선택으로 다시 검출하세요. 장면을 바꾸면 박스 연결과 BB 제외는 다시 지정하고 명단 번호·색상·코트는 유지합니다.
  7. 분석은 초기 설정 장면부터 시작합니다. 영상 끝까지 분석하거나 종료 시각만 지정한 뒤 초기 설정 저장 · 분석 준비를 누릅니다. 다른 경기들도 설정을 저장한 뒤 준비된 경기 모두 분석 시작을 누르세요. 한 경기만 시작하려면 해당 행의 1차 분석 시작을 누릅니다. 로컬 모드에서는 초기 설정 확정 · 트래킹 시작으로 바로 시작합니다. 이전 장면은 분석하지 않습니다. 지정한 코트와 유니폼이 처음부터 적용됩니다. GPU는 MPS/CUDA를 자동 선택하며 GPU가 없으면 CPU를 직접 선택합니다.
  8. 분석 목록에서 진행률·취소·재시도를 확인합니다. 남은 시간은 지금까지의 처리 시간과 완료한 분석 프레임 수로 계산한 평균 속도에 따라 갱신됩니다. 모델 준비 중에는 계산 중, 추적이 끝나면 결과 저장 중으로 표시합니다. 완료 후 작업 시작을 누르면 초기 등번호와 유니폼을 이어 받은 영상·FPA가 열립니다. 연결이 모호한 선수는 억지로 지정하지 않고 작업 화면에서 확인하도록 표시합니다.

분석 목록의 삭제를 누르면 삭제한 분석으로 이동합니다. 진행 중인 항목은 중지 후 삭제로 처리하며 중지가 끝나면 복원할 수 있습니다. 복원한 중단 작업은 다시 분석으로 시작합니다. 휴지통의 영구 삭제를 누르고 확인하면 분석 결과와 서버 검수가 실제로 삭제됩니다. 다른 분석이 함께 쓰지 않는 원본 영상과 초기 장면도 삭제됩니다. 영구 삭제는 복원할 수 없으며 다운로드한 백업은 남습니다.

탭을 오가도 초기 설정과 FPA 초안은 유지됩니다. 대기 중인 경기는 서버 재시작 후에도 이어서 처리합니다. 처리 도중 서버가 종료된 경기는 중단됨으로 표시되며 재시도할 수 있습니다. 초기 장면 검출도 GPU 대기열을 사용하므로 여러 경기의 초기 설정을 먼저 마친 뒤 일괄 분석을 시작하는 순서가 편리합니다. 업로드가 완료되고 분석 대기열에 들어간 뒤에는 브라우저를 닫거나 컴퓨터를 꺼도 됩니다. 처음 기록할 시점에 13명이 잘 보이는 장면을 선택하세요. 작업 화면도 해당 시점부터 시작하며 영상·FPA 시각은 원본 기준을 유지합니다.

코트 밖으로 나간 선수도 신원을 유지하기 위해 주변 박스가 표시됩니다. 박스 표시와 코트 내부 판정은 다릅니다. 코트 경계는 고정된 화면을 기준으로 하므로 카메라가 크게 움직이면 구간을 나눠 설정하세요.

01 · 파일

네 가지 버튼의 차이

버튼여는 / 저장하는 파일역할
트래킹 결과 열기tracks.json시간별 선수 박스 위치와 TRACK ID를 불러옵니다. 새 분석을 실행하는 버튼은 아닙니다.
영상 열기같은 경기의 원본 영상 또는 preview.mp4트래킹 결과 위에 재생할 영상을 연결합니다. 먼저 해당 영상의 트래킹 결과를 열어야 합니다.
작업 복원이전 이름: 검수 불러오기백업한 …-review.json등번호 지정·유니폼 색상·재연결 확정/거절·FPA 기록·입력 초안을 복원합니다. 같은 트래킹 실행의 결과를 먼저 열어 주세요.
작업 백업이전 이름: 검수 내보내기현재 작업의 …-review.json현재 작업을 파일로 내려받습니다. 영상과 원본 트래킹 결과 파일 자체는 포함하지 않습니다.

새 영상: 영상 트래킹 → 초기 설정 → 트래킹 시작 → 완료 후 작업 시작. 이미 별도로 분석한 파일은 아래 네 가지 버튼으로 불러올 수 있습니다.

영상 아래 영상 기준에서 원본인지 분석 구간 미리보기인지 확인하세요. 서로 다른 영상·분석 구간을 연결하면 박스와 선수의 위치가 맞지 않습니다.

02 · 선수 설정

초기 설정과 작업 중 수정

코트·유니폼·13명 초기 설정은 영상 트래킹 탭에서 분석 전에 완료합니다. 작업 화면의 선수·유니폼 수정은 이미 등록한 명단과 색상을 보정할 때 사용합니다.

  1. 등번호를 바꾸려면 영상의 선수 박스를 선택한 뒤 선수 번호·트랙 검수에서 명단·등번호·적용 범위를 확인하고 선수 번호 적용을 누릅니다.
  2. 색상을 바꾸려면 선수·유니폼 수정에서 스포이드로 추가하거나 잘못 찍은 색상을 제거합니다.
  3. 일부 초기 지정이 연결되지 않았거나 기존 결과 파일을 직접 연 경우에는 13명을 해당 장면에 연결한 뒤 초기 13명 확정으로 자동 재연결을 활성화합니다.

초기 박스 번호와 TRACK ID

초기 장면의 #번호는 한 장면의 검출 번호입니다. 최종 TRACK ID와 다릅니다. 같은 장면의 위치를 대조해 작업자가 지정한 명단과 등번호를 최종 트랙에 연결합니다.

코트 밖에서도 신원 유지

킥인 준비·공 회수로 코트 밖에 나가도 명단 선수라는 사실은 유지합니다. 미지정 외부 박스는 경계 후보로 구분해 확인합니다.

작업 중 바꾼 색상은 저장되며, 검수 반영을 누르면 선수 재연결에 적용됩니다. 이미 생성한 BB 추적에 적용하려면 영상 트래킹에서 해당 색상으로 다시 분석해야 합니다.

03 · FPA 입력

장면을 기록하고 선수 번호 연결하기

  1. 영상에서 이벤트 시점을 찾고, 상단의 팀·공격 방향·피리어드를 선택합니다. 팀을 바꾸면 공격 방향도 반전됩니다.
  2. Single 모드에서 오른쪽 피치에 좌표를 찍고 기존 FPA 스탯 코드를 입력한 뒤 Enter로 저장합니다. 피치 우클릭은 마지막 좌표를 취소합니다.
  3. 피치 제목 옆 기록된 로그를 열어 번호를 연결할 행을 선택합니다. 영상도 해당 기록 시각으로 이동합니다.
  4. 행위자 연결 또는 수신자 연결을 선택한 뒤 영상의 선수 박스를 클릭합니다. 박스에 지정된 팀·등번호가 데이터 행에 반영됩니다.
  5. 좌표나 코드도 수정하려면 선택 로그 수정을 눌러 피치로 불러옵니다. 수정 후 Enter를 누르면 같은 행에 저장됩니다.

번호가 미지정된 박스는 먼저 선수 검수 패널에서 지정하세요. 행과 선수의 팀이 다르면 연결하지 않습니다. 새 입력을 누르면 선택한 기록의 편집을 끝내고 새 이벤트를 작성합니다.

이미 제공되는 Dual 모드

Before/After의 선수 점과 패스 화살표로 장면을 기록합니다. 액션 저장 후에는 로그에서 장면을 선택하고 선택 장면 수정 → 수정 저장으로 편집합니다. 기본 작업은 Single로 진행해도 됩니다.

그림자·중복 BB를 숨기려면 영상 BB 선택 → 선수 번호·트랙 검수 펼치기 → 적용 범위 확인 → 선택 BB 제외를 누르세요. 되돌리기로 복원할 수 있고, 영상 위 제외 트랙을 켜면 제외한 BB가 다시 보입니다. 새로고침 뒤에는 해당 BB를 선택하고 이 구간의 지정 해제 또는 선수 번호를 다시 적용할 수 있습니다.

초기 BB 제외는 초기 설정 프레임에 적용되며, 이후 새로 생기는 ID를 영구 차단하지 않습니다. 분석 후 제외는 선택한 트랙의 지정 범위에 적용되고 원본 영상·검출 파일은 보존됩니다.

04 · 검수

재연결 검수에서는 무엇을 하나요?

선수가 가려졌다가 나오거나 공을 가지러 코트 밖에 다녀오면 TRACK ID가 바뀔 수 있습니다. 새 트랙을 기존 명단의 누구와 연결할지 확인하는 곳입니다. FPA 이벤트의 종류를 고르는 기능과는 별개입니다.

작업을 열면 영상·FPA가 먼저 준비되고, 선수 재연결은 별도로 계산합니다. 위 진행 표시에서 색상 확인 → 중복 정리 → 선수 재연결 상태를 볼 수 있습니다. 계산 중에도 영상 재생·이벤트 입력·수동 번호 지정은 가능하며, 자동 번호와 중복 정리는 완료 후 반영됩니다. 계산 중지와 검수 반영 · 재연결은 이 재연결 계산에만 적용됩니다.

같은 결과와 선수 설정으로 다시 열면 이 브라우저에 저장된 계산 결과를 재사용합니다. 번호·유니폼·초기 설정·장면 확인을 변경해도 자동 재계산하지 않습니다. 수정들을 모아 검수 반영 · 재연결을 눌러야 계산합니다. 계산 중 추가한 수정은 다음 반영을 위해 남겨두며, 새로고침해도 미반영 상태가 유지됩니다. FPA 이벤트 편집은 이 계산과 별개입니다. 이 저장 기능은 작업 백업을 대신하지 않습니다.

이전 TRACK#8→새 TRACK#341같은 선수인가?번호는 설명용 예시입니다. 앞뒤 영상과 유니폼·위치·움직임으로 확인하세요.

자동 연결된 구간

  1. 영상 확인을 눌러 해당 시점의 박스를 봅니다. 선수 검수 패널도 함께 열립니다.
  2. 앞뒤로 탐색하며 기존 선수와 같은 사람인지 확인합니다.
  3. 맞으면 연결 확정, 다르면 거절을 누릅니다. 열린 선수 검수 패널에서도 처리할 수 있습니다.

보류된 트랙

  1. 영상 확인으로 새 트랙을 확인합니다.
  2. 제안된 선수 후보를 누르면 검수 폼에 그 선수가 채워집니다. 이 단계에서는 아직 확정되지 않습니다.
  3. 명단·번호·적용 범위를 확인한 뒤 선수 번호 적용을 누릅니다. 다른 선수라면 명단에서 직접 고릅니다.

점수는 색상·이동·시간을 비교한 후보 순위이며 정확도 확률이 아닙니다. 판단이 어렵다면 보류한 채 다음 구간을 확인하세요. 잘못 확정했으면 되돌리기 또는 적용 범위를 지정해 수정할 수 있습니다.

05 · 시간

영상 시각과 경기 시각 맞추기

영상 시간 동기화가 켜져 있으면 재생·탐색·프레임 이동에 FPA 경기 시각이 따라갑니다. 경기 시각을 직접 입력하고 Enter를 누르거나 ±1s 버튼을 누르면 영상도 이동합니다.

경기 시각 = 원본 영상 시각 − 피리어드 시작 시각

피치 아래 시간 기준에서 시작 시각을 설정합니다. 예를 들어 경기 시작이 원본 영상 5초라면 영상 31.25초는 경기 00:26.250입니다. 미리보기 영상도 화면에는 원본 영상 기준 시각을 표시합니다.

기존 로그를 수정하는 동안에는 시간 고정으로 전환해 재생 때문에 기록 시각이 바뀌지 않게 합니다. 시각을 바꾸려면 입력창에서 직접 수정하세요.

06 · 저장

작업 백업과 FPA 내보내기

다음에 이어서 작업

상단 작업 백업으로 JSON을 저장하세요. 분석 목록에서 같은 작업을 열면 자동 저장이 복원됩니다. 별도 파일로 작업했다면 같은 tracks.json과 영상도 함께 보관합니다. 백업을 복구할 때 작업 복원으로 JSON을 불러오면 됩니다.

FPA 분석 데이터 사용

기록된 로그 → 분석 및 내보내기는 FPA 분석용 XLSX를 만듭니다. 기존 FPA XLSX는 같은 화면의 수정 및 불러오기로 불러옵니다. 선수 트래킹 작업 백업과 용도가 다릅니다.

작업은 현재 브라우저·사이트 주소에 자동 저장됩니다. 다른 브라우저나 PC로 옮길 때는 JSON 백업을 사용하세요. 같은 영상을 새로 트래킹하면 TRACK ID와 실행 정보가 달라져 기존 백업을 그대로 복원할 수 없습니다.

FPC에서 분석 목록으로 연 작업은 검수가 서버에 자동 저장됩니다. 서버 저장됨 표시를 확인하세요. 로컬 파일로 연 작업은 브라우저에 저장되므로 JSON 백업이 필요합니다. 같은 분석을 여러 창에서 수정하면 서버 버전 충돌을 알려 덮어쓰기를 방지합니다.

07 · 히트맵

필드 선수 10명 히트맵

초기 설정은 홈 6명·원정 6명·심판 1명, 총 13명입니다. 키퍼 2명과 심판을 제외한 10명의 위치를 집계합니다. 작업 화면 오른쪽 선수·트랙 검수에서 연결을 확인한 뒤 히트맵을 선택하세요. 자동 연결을 포함해 만들거나 수동 지정만 골라 비교할 수 있습니다.

박스가 없어져도 명단은 경기 끝까지 유지합니다. 같은 그룹에서 한 명만 없어졌고 나머지가 계속 확인되면, 새 박스의 연속 색상·이동·겹침 여부를 확인해 더 강하게 재연결합니다. 여러 명이 사라지면 전체 후보를 일대일로 비교하며, 구분할 근거가 부족한 경우 보류합니다. 키퍼의 초기 위치는 보조 근거이고 골대 근처에만 가두지 않습니다.

좌표는 지정한 코트 네 꼭짓점으로 원근 보정합니다. 일반 시점은 박스 하단, 수직에 가까운 촬영은 박스 중앙을 선택하고 코트 방향을 확인하세요. 카메라가 이동하거나 줌이 바뀌면 코트 보정이 달라지므로 해당 구간을 나누고 다시 설정해야 합니다. 40×20m 피치는 표시용이며 실제 이동거리 측정 기능은 아닙니다.

색상 충돌·심한 겹침·코트 밖 좌표·동일 선수 중복 박스는 집계에서 제외합니다. 관측이 끊긴 구간에 가상의 이동 경로를 채우지 않습니다. 유효 관측률은 전체 분석 시간 중 쓸 수 있는 관측 시간으로, 선수 번호의 정확도를 보증하는 수치가 아닙니다. 자동 구간은 영상 검수가 필요합니다. 교체나 키퍼 역할 변경이 있는 경기는 해당 시점에서 분석 구간을 나누고 명단을 다시 지정하세요.

각 선수 PNG 저장과 10명 PNG 저장은 제목·선수 번호·품질 문구 없이 히트맵만 내보냅니다. 퀸컵용 흰색 피치, 분홍 라인(#E162A7), 연분홍 바깥 배경(#EFCADE)을 사용합니다. 선수별 PNG는 1320×720px이며 파일명으로 팀·번호를 구분합니다. 이름과 유효 관측률은 화면에서 확인할 수 있습니다. 원본 시각·정규화 좌표·자동/수동 출처와 관측률을 담은 좌표·품질 JSON을 제공합니다. 새 추적에는 겹친 신규 중복/그림자 후보 억제가 적용되지만, 사람과 떨어진 그림자는 여전히 수동 제외가 필요할 수 있습니다.

08 · 장면 확인

초기 한 장면 → 1차 추적 → 검수·재연결 반복

초기 13명 지정 이후, 작업 화면 오른쪽 장면 확인을 선택합니다. 작업 화면 위의 2차 검수 시작을 누르면 추천 장면으로 이동합니다. 추가 태깅을 저장한 뒤 수정 모아 2차 결과 만들기를 누르세요. 완료 후에는 3차 검수 시작이 나타나며 같은 흐름을 계속 반복할 수 있습니다. 결과 생성 이력에는 회차별 반영 시각과 누적 확인 장면 수를 기록합니다. 영상 트래킹에서는 초기 한 장면만 설정합니다. 매번 검수를 반영하면 남은 미연결 구간에서 선수가 서로 떨어져 보이는 장면을 최대 5개 추천합니다. 긴 공백이 시작된 뒤 번호를 확인하기 좋은 장면을 우선하며, 시간순이 아닌 개선 우선순위로 표시합니다. 카드의 번호는 확인 후보이며, 미연결 시간은 관련 구간의 선수별 합계로 실제 회복량을 보장하지 않습니다. 같은 공백을 여러 번 추천해 장면 수를 채우지 않습니다. 이번 추천 수를 10·15개로 바꿀 수 있지만 전부 확인할 필요는 없습니다. 추천 장면 외에 원하는 시점도 확인할 수 있고, 누적 장면 수나 검수 회차에 따른 완료 조건은 없습니다.

  1. 추천 시각을 누르거나 영상을 원하는 시점에 멈추고 현재 장면 확인을 누릅니다.
  2. 영상의 선수 BB를 클릭하고 명단에서 번호를 선택합니다. 확인한 BB에는 ✓가 붙습니다. 확실히 보이는 선수만 지정하며 매번 13명을 모두 지정할 필요는 없습니다.
  3. 화면의 예상 번호를 모두 직접 확인했다면 화면의 예상 번호 모두 확인으로 묶어 선택할 수 있습니다. 틀린 번호는 BB와 번호를 다시 선택해 수정하세요.
  4. 확인 저장으로 장면을 모은 뒤 검수 반영 · 재연결을 누릅니다. YOLO 분석을 다시 실행하지 않고 기존 검출 결과의 번호 연결을 계산합니다.
  5. 반영 결과를 보고 추가 태깅과 재연결을 필요한 만큼 반복합니다. 히트맵에서 평균과 최저 선수의 유효 관측률, 선수별 최장 빈 구간을 확인합니다. 평균이 높아져도 특정 선수가 계속 비어 있다면 추가 확인이 필요합니다.

확정은 실제 관측된 한 프레임에만 저장합니다. 그 앞뒤의 연결은 자동 추정으로 남습니다. 경합·큰 위치 변화·끊긴 관측에서 트랙을 나누고 확인된 장면을 근거로 경로를 연결합니다. 앞뒤 확인 번호가 충돌하는 구간은 보류하며 같은 선수를 두 BB에 동시에 자동 지정하지 않습니다.

저장한 확인은 브라우저 자동 저장과 작업 백업에 포함됩니다. 반영 전에는 히트맵을 새로 만들 수 없습니다. 장면 삭제는 확인 정보를 제거하며 원본 검출·영상은 보존됩니다. 실수했다면 선수·트랙 검수 → 되돌리기로 복원할 수 있습니다. 번호 확인만으로 검출되지 않은 선수의 좌표나 긴 누락 구간을 만들어 내지는 않습니다.
