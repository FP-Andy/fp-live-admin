# FCM 골키퍼 카드 수치

## 계산 기준

- 기대 실점(xG)은 상대 팀의 모든 슈팅 xG 합계다. 골, 선방된 유효슈팅, 빗나간 슈팅, 블록된 슈팅을 포함한다.
- FPA 엑셀은 현재 `Shot` + 결과 태그 형식과 이전 `Goal`, `Shot On Target`, `Shot`, `Blocked Shot` 형식을 모두 인식한다.
- 연결된 경기에 FLA `XG` 이벤트가 있으면 Broadcast와 같은 이벤트에서 실점·기대 실점·선방을 계산한다. 기존 값이 0이 아니어도 현재 합계로 갱신한다.
- 경기 전체에 FLA 슈팅 기록이 없으면 FPA 값과 세이브 맵을 유지한다. FLA 기록은 있으나 상대 슈팅이 없으면 상대 합계는 0이다.
- 선수 후보, 저장된 제출 내역 조회, 개별·일괄 PNG 생성에 같은 보정을 적용한다. 기존 제출 원문은 조회 시 덮어쓰지 않는다.
- 캐칭·펀칭 등 다른 항목, 선방 항목에 덧붙인 승부차기 설명, 사용자가 선택한 항목의 순서와 개수는 유지한다.

기존 FLA 연동 카드는 다시 생성하면 수정된 수치가 반영된다. 엑셀만 사용하는 경기는 파일을 다시 분석하고 수정된 후보를 선택해 제출한다. 이미 다운로드한 PNG 파일 자체는 변경되지 않는다.

## 회귀 검증

`apps/api/tests/test_goalkeeper_cards.py`는 실제 엑셀 분석, SQLite 이벤트 조회, 제출 내역 조회 및 1920×1080 PNG 생성을 검증한다. 테스트 데이터에서 기존 코드가 골의 xG `0.194`만 합산하던 값을 전체 상대 슈팅의 합계 `2.100`으로 수정했는지 확인한다. 이 데이터는 사용자 스크린샷의 오류 패턴을 재현한 예시이며 실제 경기 원본은 아니다.

```sh
runtime/auth-venv/bin/python -m unittest discover -s apps/api/tests -p test_goalkeeper_cards.py -v
```
