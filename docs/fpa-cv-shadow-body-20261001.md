## 원인과 처리

서울–안양은 작은 몸 BB와 몸·그림자를 포함한 큰 BB가 동시에 존재한다. 큰 BB가 오히려 검출 신뢰도가 높고, 그 안의 어두운 그림자가 홈 유니폼 근거로 사용되어 단순 IoU·신뢰도·동일 팀 조건으로 제거되지 않았다. 초기 안양 #3도 이 때문에 홈 색상 충돌로 연결이 보류됐다.

1. 큰 BB 안에 작은 몸 BB가 하나만 들어 있고, 면적·포함률·암부 비율 조건을 통과하는 쌍을 찾는다.
2. 여러 객체에서 공통으로 나타나는 그림자 방향을 시간 구간마다 추출한다. 경기명·팀·ID·고정 그림자 방향을 코드에 넣지 않는다.
3. 반복 관측과 상대 위치 안정성을 확인한 구간만 큰 BB를 숨긴다. 몸 BB의 좌표와 검출 신뢰도는 수정하지 않는다.
4. 초기 수동 번호가 큰 BB에만 있으면 실제 두 BB가 함께 관측된 구간에서 몸 BB로 승계한다. 이후 연결은 기존 재연결 로직이 담당한다.
5. 확인된 중복 직전·직후의 큰 BB에서는 암부 색상의 가중치를 낮춘다. 미래 유니폼을 복사하거나 새 좌표를 만들지 않는다.
6. 서로 다른 수동 번호, 잠긴 지정, 확인 장면, 명시적 연결 거절, 이전에 분리되어 관측된 두 객체, 한 BB 안에 두 몸이 있는 경합은 보호한다.

검수 배치·워커·캐시가 동일한 설정과 수정된 색상 근거를 사용한다. 설정 변경 후 검수 반영 전에는 서버가 새 스냅샷 저장을 거절한다. 기존 설정이 없는 검수는 꺼짐으로 호환한다.

## 남은 확인

- 관측률 증가는 신원 정확도 측정값이 아니다. 90초 비교 결과를 전체 경기 관측률로 해석하지 않는다.
- 안양 #2·#5는 중복 이외의 색상·번호 단절을 추가 검수해야 한다.
- 작은 몸 BB 없이 큰 몸·그림자 BB만 나온 구간은 유지한다. 추후 몸 영역 재검출/수동 지정이 필요한 별도 대상이다.
- 전체 경기의 번호 승계와 경합·접촉 장면을 더 검수한 뒤 운영 배포와 새 스냅샷을 진행한다.
- 다른 경기에서도 그림자 방향이 충분히 합의되지 않거나 실제 두 선수를 구분하기 어려우면 제거하지 않는다. 현재 기하·색상 임계값의 일반화 성능은 다른 영상에서 별도 확인해야 한다.
