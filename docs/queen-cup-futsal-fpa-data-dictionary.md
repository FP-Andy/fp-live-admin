# 퀸컵 풋살 FPA 데이터 사전 및 수집 로직

## 1. 적용 원칙

- 스포츠: `FUTSAL`, 대회 프로필: `FUTSAL_6V6_QUEENCUP`
- 피치 원본 좌표: 실제 피치 기준 `0–40m × 0–20m`을 기본값으로 저장한다. 실제 피치가 다르면 경기 프로필의 길이·폭으로 저장하고, 분석 시 공격 방향을 항상 오른쪽 골문 기준으로 정규화한다.
- FPA는 선수 개별 액션과 좌표를, FLA는 경기 시계·점유·공격 방향·슈팅·도미넌스를 기록한다. 동일 슈팅은 `match_id + period + clock + shooter + coordinate` 기준으로 연결해 중복 집계를 막는다.
- `SS` 같은 기존 FPA 코드를 최대한 유지한다. `c/cc`는 풋살의 킥인 실패/성공으로 화면명을 바꾸고, 인플레이에서의 롱킥·롱패스는 패스 코드에 신규 태그 `lk`를 붙여 `s.lk`/`ss.lk`로 구분한다.
- 모든 성공률은 `성공 / (성공 + 실패)`로 계산하고, 육각 값은 `10분당 기여량` 또는 `성공률`을 역할별 기준선에 맞춰 0–100으로 변환한다. 원시 시도·성공·실패 수는 항상 함께 보인다.

### 3.3 수비 네 지표와 압박 해제의 판정 기준

수비 육각의 `수비 능력`은 아래 네 이벤트의 10분당 합으로 계산한다. 점유를 되찾는지와 공이 이동 중인지에 따라 같은 장면을 중복 기록하지 않는다.

| 상황 | 우리 팀이 점유를 얻음 | 우리 팀이 즉시 점유를 얻지 못함 |
| --- | --- | --- |
| 공이 이동 중인 패스/경로 | 인터셉트 `q` | 차단 `ww` |
| 상대가 공을 소유해 플레이 중 | 태클 `aa` | 블락 `qw` - 상대 슈팅을 막은 경우 |

- `인터셉트`: 이동 중인 상대 패스를 가로채 우리 팀이 공을 확보한 경우다.
- `태클`: 상대가 공을 컨트롤하고 있을 때 직접 경합해 공을 뺏은 경우다.
- `차단`: 이동 중인 패스 경로를 건드려 위험을 끊었지만, 공이 루즈볼이 되거나 상대에게 남은 경우다.
- `블락`: 상대 소유에서 나온 슈팅을 막아 골문 위협을 제거한 경우다.

`압박 해제 패스(pb)`는 단순 전진 패스가 아니다. 볼 소유자가 가까운 상대 압박을 받고 있을 때, 압박자 또는 압박선을 넘어 동료/빈 공간으로 패스해 팀이 다음 플레이를 이어가는 경우다. 예를 들어 픽소가 전방 압박을 받다가 알라에게 패스해 압박선 뒤에서 다음 전진이 시작되면 `ss.pb`를 입력한다. 압박을 받지 않은 일반 전진 패스, 또는 드리블로만 상대를 벗어난 경우에는 `pb`를 붙이지 않는다.

드리블과 돌파도 분리한다.

- `드리블 rr/r`: 볼을 소유한 채 운반한 행동이다. 상대를 제치지 않아도 전진·방향 전환·공간 운반이 있으면 기록한다.
- `돌파 ee/e`: 상대 수비수 한 명 또는 수비선을 실제로 넘어서 위험지역/전진 공간으로 들어간 행동이다. 1대1에서 제친 경우, 등지고 받은 피보가 돌아선 경우가 대표적이다.

## 4. 슈팅 위험도·결정력·슈팅 능력 로직

### 4.1 공통 원본

각 슈팅마다 아래 값을 자동 계산한다.

| 필드 | 산출 방식 | 용도 |
| --- | --- | --- |
| `distance_to_goal_m` | 정규화된 상대 골대 중심과 슈팅 좌표의 거리 | 슈팅 위험도 원본 |
| `shot_threat` | `distance_to_goal_m`을 거리 가중표로 변환한 0–1 기회점수 | 팀/선수 누적 기회 질 |
| `threat_band` | High / Medium / Low | 결정력·슈팅 능력 분리 |
| `shot_result` | Goal / On Target / Off Target / Blocked | 성공/실패 판정 |
| `shot_context` | 오픈플레이 / 킥인 / 코너 / 프리킥 / PK / 역습 | 후속 QC-xG 학습, 리포트 필터 |

거리 가중표는 모의경기 2경기에서 확인해 `Shot Threat v0.1`로 동결하고, 모든 리포트에 동일 버전을 적용한다. 나중에 데이터가 쌓여도 원본 거리·좌표는 바꾸지 않고 가중표 버전만 교체해 재계산한다.

### 4.2 세 축의 분리

| 육각 축 | 산식의 핵심 | 높아지는 경우 | 낮아지는 경우 |
| --- | --- | --- | --- |
| 슈팅 위험도 | `Σ shot_threat / 10분` | 골대 가까운 지점에서 많은 슈팅 기회를 만듦 | 먼 거리 위주의 슈팅 또는 적은 시도 |
| 골 결정력 | `High 위험도 골 / High 위험도 슈팅`을 표본 보정 | 가까운 좋은 기회를 골로 마무리 | 가까운 기회를 놓침 |
| 슈팅 능력 | `Low·Medium 위험도에서의 골·유효슈팅 기여 / Low·Medium 시도` | 어려운 위치에서도 골 또는 유효슈팅으로 만듦 | 먼 거리 슈팅을 반복해도 골/유효슈팅이 적음 |

PK와 자책골은 세 축의 기본 계산에서 분리한다. PK는 별도 결과 지표로 보관하고, 자책골은 슈터의 슈팅 능력·결정력에 넣지 않는다.

## 6. 현장 수집 순서

1. **FLA**가 경기 시계, 점유, 공격 방향, 온코트 6명, 모든 슈팅을 빠르게 확정한다.
2. **FPA**가 같은 시각을 기준으로 패스·드리블·경합·수비·킥인·세이브를 좌표와 코드로 남긴다.
3. 경기 종료 뒤 영상으로 실패/성공, 수신자, 태그, 세컨드볼, 압박 해제, 수적우위를 보완한다.
4. QA는 홈/원정 방향, 슈팅 중복, 출전시간, FLA 슈팅과 FPA 슈팅의 연결, 수신자 번호, 좌표 범위를 확인한다.
5. 리포트 생성 시 `role`, `minutes_played`, `metric_version`, `shot_threat_version`을 함께 저장해 이후 재산출 가능하게 한다.
