# FPC 계정과 테마

## 로그인 정책

- 관리자: 엑셀의 `계정(아이디)` + `비밀번호`. `사용자명`은 화면 표시 이름이며, 등록된 계정은 모두 ADMIN(SUPERADMIN)입니다.
- 운영자: 로그인 화면에서 `운영자` 선택 → 자유 사용자명 + 관리자가 설정한 공통 액세스 코드.
- 코드 설정: **System → 계정 · 접근 → 운영자 공통 코드**. 최초에는 운영자 로그인이 중지되어 있으며 관리자가 8자 이상 코드를 저장하면 활성화됩니다.
- 코드 변경·중지는 기존 운영자 세션을 만료시킵니다. 관리자 세션은 유지됩니다. 저장한 코드는 다시 조회할 수 없습니다.
- 관리자 계정의 비밀번호 변경·허용 목록 제외 시 해당 계정의 기존 세션은 무효가 됩니다.
- 이전 공통 ADMIN/OPERATOR 환경변수 키와 서명 쿠키는 더 이상 인증에 사용하지 않습니다.

## 비공개 관리자 파일 준비

API 실행 환경의 Python에 `openpyxl`이 필요합니다. 원본 엑셀은 수정하지 않습니다.

```sh
python scripts/provision_admin_accounts.py '/absolute/path/to/accounts.xlsx'
```

기본 출력은 Git에서 제외된 `runtime/auth/admin-accounts.json`입니다. 파일 권한은 600이며, 비밀번호는 개별 salt를 사용한 PBKDF2-SHA256 해시로만 저장합니다. 계정 문자열·원본 비밀번호는 로그로 출력하지 않습니다. 동일 비밀번호를 재가져오면 기존 해시를 재사용합니다.

운영 배포 시 **코드 배포 전에** 이 비공개 파일을 운영 호스트의 `runtime/auth/admin-accounts.json`에 안전하게 전달해야 합니다. Git이나 프런트엔드 정적 파일에 포함하지 않습니다. Compose의 `FPC_ADMIN_ACCOUNTS_FILE`은 기본적으로 `/app/runtime/auth/admin-accounts.json`을 가리킵니다. 설정된 파일이 없거나 잘못되면 API 시작이 실패합니다. 파일을 바꾼 뒤 API를 재시작하면 허용 목록을 동기화합니다. 기존 경기 이력의 User 행은 삭제하지 않습니다.

현재 작업에서는 운영 배포나 운영 DB 변경을 하지 않았습니다. 로컬 계정 파일만 준비했습니다.

## 세션

쿠키에는 무작위 세션 토큰, 서버 DB에는 토큰 해시와 만료 시각을 저장합니다. 로그아웃 시 폐기하며 기본 유효기간은 14일입니다. 운영 환경에서는 기존 FineLudens 서브도메인 공유 Secure/HttpOnly 쿠키를 유지합니다. 잘못된 로그인은 접속 IP당 15분에 20회까지 허용합니다. 프록시가 IP를 전달할 때는 신뢰할 프록시 범위를 서버에서 제한해야 합니다.

## 테마

로그인 화면 우측 상단 및 FPC 상단 바에서 다크/화이트 모드를 전환합니다. 기본은 다크이며 선택은 브라우저에 저장되고 탭 간 동기화됩니다. 콘솔 전용 CSS로 적용하여 중계 그래픽과 내보내기 이미지의 색상을 유지합니다.

## 로컬 검증

```sh
runtime/auth-venv/bin/python -m unittest discover -s apps/api/tests -v
cd apps/web
npm run build
```

인증 테스트는 실제 프로덕션 인증 라우터를 SQLite 테스트 DB에서 실행합니다. 운영 Postgres 및 외부 송출 서비스 통합 검증은 배포 과정에서 별도로 진행합니다.

- 인증 경계 테스트 7개 통과: 허용 목록·비밀번호, 최초 운영자 차단, 권한 분리, 코드 변경/중지, 로그아웃/만료, 관리자 변경 시 세션 폐기, 이전 공통 키 거부 및 시도 제한.

- 추가 요청에 따라 `simon@fineplay.kr`, `shawn@fineplay.kr`을 같은 비공개 관리자 허용 목록에 추가했습니다. 현재 로컬 관리자 6명이며, 두 신규 계정의 로그인·관리자 접근·로그아웃을 실제 인증 라우터와 로컬 SQLite DB에서 검증했습니다. 추가 비밀번호도 해시만 저장합니다.
- 브라우저에서 관리자 로그인 → 코드 저장 → 자유 이름 운영자 로그인 → 코드 변경으로 기존 운영자 세션 만료 → 로그인 중지를 검증.
- 로그인 문구 중심 오차 0px. 355px 로그인 및 394px FLA·접근 설정에서 가로 넘침 없음. 모바일 접근 설정은 한 열, 코드 입력 높이 45px.
