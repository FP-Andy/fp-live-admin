# KFA PDF 명단과 Broadcast 팀 브랜딩

## 운영 흐름

1. FLA 경기 제어 → 설정 → 명단에서 **PDF 명단 업로드**를 선택합니다. 기본값은 **자동 인식**입니다.
2. PDF의 좌우 표 배치로 명단을 구분하고, 현재 경기 팀명이 인식된 팀명과 일치하면 홈·어웨이 방향을 맞춥니다. PDF 내부 텍스트 객체 순서는 사용하지 않습니다.
3. 인식한 팀명·인원과 필드/골키퍼의 상의·하의·양말 색상을 확인합니다. 방향을 직접 지정하거나 **홈·어웨이 바꾸기**를 사용할 수 있습니다. 바꾸기는 명단·팀명·유니폼 정보를 함께 이동합니다.
4. **FCM → Templates → 팀 로고**에서 대회와 팀명을 선택하고 PNG/JPG/WEBP를 등록합니다. 같은 대회·팀명으로 다시 등록하면 로고가 교체됩니다. 파일 크기는 최대 5MB, 해상도는 최대 1,600만 화소입니다.
5. Broadcast는 PDF의 **필드 상의** 색상과 등록된 팀 로고를 자동으로 사용합니다. 로고는 FCM 골키퍼 카드에도 연결됩니다. 주요선수 카드의 기존 템플릿 디자인은 그대로 사용합니다.
6. Broadcast의 경기별 수동 색상·로고가 있으면 수동 설정이 우선합니다. **PDF·팀 로고 자동 적용**을 누르면 해당 경기의 색상·로고를 자동 설정으로 되돌립니다. 점수·타이머 등은 유지합니다.

색상은 KFA가 제공하는 이름을 그대로 보존하며, 화면에는 해당 이름의 대표 HEX 색상을 사용합니다. 알 수 없는 색상명은 임의로 변환하지 않습니다. 정확한 방송 색상은 Broadcast에서 조정할 수 있습니다. 밝은 색상에는 가독성을 위해 어두운 숫자를 표시합니다.

팀 로고는 대회 코드와 정규화한 팀명으로 일치시킵니다. 공백·일반 구두점·영문 대소문자·맨 끝의 FC는 구분하지 않으며, 임의의 부분 문자열이나 정규식으로 다른 팀 로고를 연결하지 않습니다. 다른 대회에서는 별도로 등록합니다.

## 데이터와 반영

- PDF 파서: `apps/api/app/lineup_pdf.py`, pypdf 6.10.0의 layout 추출 사용. 최대 20MB / 30페이지. 이미지로만 된 스캔 PDF는 명확한 오류와 직접 입력 안내를 제공합니다.
- 명단 정보: `Match.metadata_json.lineups`의 `teams`, `team_names`, `uniforms`, `detected_by`. 기존 선수 필드를 유지하며 `starter`와 `isSubstitute`를 함께 제공합니다.
- 로고: 새 `team_logos` 테이블에 `(competition_class, team_key)` 고유 제약. API 시작 시 기존 `Base.metadata.create_all` 흐름에서 생성합니다. 파일은 기존 Broadcast 영속 저장소의 `logos` 하위에 저장합니다.
- API: 인증된 사용자만 `GET/POST /api/fcm/team-logos`, `DELETE /api/fcm/team-logos/{id}` 사용 가능. 공개 그래픽은 기존 `/api/broadcast/assets/logos/{filename}`를 사용합니다.
- `broadcast.branding_sources`는 `pdf`, `team_logo`, `manual`, `default`를 구분합니다. 일반 상태 저장 이후에도 자동 값은 최신 PDF/로고를 계속 따릅니다.
- PDF 업로드·방향 변경·로고 등록/교체/해제 시 Broadcast 스냅샷 캐시를 비우고, 기존 라이브·아카이브·도미넌스 PNG를 갱신하는 작업을 예약합니다. 과거 이미지의 경기 시점과 분석 데이터는 유지합니다.
- 로고 파일명은 변경할 때마다 새로 생성합니다. 이전 이미지가 참조할 수 있으므로 교체/해제 시 과거 파일을 즉시 삭제하지 않습니다.
- 기존 경기별 수동 색상·로고는 보존합니다. 과거 기본색 `#ff7900`/`#3d22f3`는 PDF 색상이 있으면 자동으로 전환됩니다.

## 검증

`runtime/auth-venv/bin/python -m unittest discover -s apps/api/tests -v`

PDF 좌우 표, PDF 객체 순서 역전, 팀명 방향 보정, 미확인 색상, 선발·후보, 중복 등번호, 수동 방향 변경, 관리자/운영자 접근, 로고 파일 검증, 대회별 매칭, 교체·해제, 수동 브랜딩 유지/초기화, 실제 FastAPI 업로드와 상태 저장 경로를 검증합니다.

첨부된 원본 KFA PDF에서도 홈 경주한수원FC / 어웨이 전북현대모터스, 양 팀 각 20명(선발 11명·후보 9명), 필드·골키퍼의 모든 유니폼 항목을 확인했습니다. 원본 PDF와 추출된 개인 명단은 소스 저장소에 포함하지 않습니다.
