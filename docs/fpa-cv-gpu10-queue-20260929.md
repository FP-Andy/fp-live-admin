# 10비트 GPU 디코딩과 배포용 대기열 제어

## 문제와 수정

4K HEVC Main 10 영상은 기존 NV12 고정 다운로드 필터에서 실패해 CPU로 전환됐다. YOLO26s는 여전히 GPU를 사용했지만 원본 디코딩·색 변환이 느려 전체 처리량은 2.31fps였다.

픽셀 형식을 FFprobe로 읽어 8비트는 기존 NV12 경로, 10비트는 P010 → planar YUV420P10LE로 다운로드한다. 미리보기는 CUDA에서 NV12로 바꿔 NVENC H.264로 저장한다.

운영 OpenCV 5.0의 libswscale 9와 CLI FFmpeg 7.1의 HDR 색 변환 결과가 달라, 10비트 분석 입력은 OpenCV에 포함된 libavutil 60 / libswscale 9를 재사용한다. 소스의 색 범위·색 공간·전달 함수·원색·크로마 위치를 전달하고, 분석 샘플만 BGR로 변환한다. ctypes의 AVFrame prefix는 libavutil 60 공개 ABI에 한정하며 다른 버전에서는 CPU로 돌아간다. 초기 장면의 OpenCV 픽셀 완전 일치 검사는 유지한다. 라이브러리를 업그레이드하면 GPU 검증을 다시 해야 한다.

모델 가중치, 입력 1280, 15Hz 샘플링, 선수·유니폼·코트·초기 설정은 변경하지 않는다. 특정 경기·트랙·시각별 분기는 없다.

공식 구현 근거:
- https://github.com/opencv/opencv/blob/4.x/modules/videoio/src/cap_ffmpeg_impl.hpp
- https://github.com/FFmpeg/FFmpeg/blob/n8.0/libavutil/frame.h

## 대기열 제어

분석 목록의 관리자는 다음 동작을 사용할 수 있다.

- **대기열 일시정지**: 이미 실행 중인 작업은 끝내고 다음 분석과 초기 장면 검출을 시작하지 않는다.
- **진행 중 분석도 중단**: 먼저 대기열을 잠근 뒤 실행 중인 두 작업 경로를 중단한다. FFmpeg·색상 프로세스도 같은 프로세스 그룹으로 종료한다.
- **대기열 재개**: 대기 작업을 순서대로 다시 실행한다.
- **분석 중단 / 대기 취소**: 해당 작업만 중단한다. 전체 대기열은 별도 제어다.
- **처음부터 다시 분석**: 저장된 영상·초기 설정을 사용해 새 분석을 만든다. 중간 프레임에서 이어서 실행하는 기능은 아니다.

`queue-state.json`에 일시정지를 영속 저장한다. 서버를 재시작해도 자동으로 풀리지 않는다. `paused && activeCount==0`일 때만 UI가 배포 가능으로 표시한다. S3 준비·저장 중이면 해당 처리가 실제로 종료될 때까지 배포 준비 상태로 표시하지 않는다. 업로드·완료 결과·검수는 보존한다.

FPC 전체 대기열 제어는 SUPERADMIN만 가능하며 기존 세션·Origin 검증을 적용한다. 로컬 워커는 기존 loopback/service-token 보호를 사용한다. `/api/tracking/queue/pause`는 `stopRunning: true` 옵션, `/api/tracking/queue/resume`은 재개다. 조회는 jobs 응답의 queue 필드다. 민감한 토큰은 UI에 전달하지 않는다.

## 검증

로컬 Python 회귀 검사 60개 실행: 58개 통과, 로컬 FFmpeg 부재에 따른 기존 미리보기 통합 검사 2개 제외. 관리자 권한, 요청 타입, 대기열 잠금 경쟁, 재시작 후 정지 유지, 대기 작업·초기 설정 보존, 기존 취소·삭제·검수 API, 파이프라인 순서를 검사했다.

실제 서울–김포 원본과 6초 스트림 복사본으로 GPU 다운로드 및 HDR 변환을 검증했다. 원시 YUV는 CPU/GPU가 일치했고, 최종 변환 경로에서 첫 비교 프레임 및 연속 샘플 5개가 BGR 픽셀까지 완전히 일치했다. 후속 30프레임도 모두 픽셀이 완전히 일치했다. 운영 분석과 병행한 읽기·색 변환 비교에서 CPU 37.29초, GPU+미리보기 26.69초로 1.40배 처리량(시간 28.4% 감소)을 확인했다. CPU 측정에는 미리보기 인코딩을 포함하지 않았다. 이는 짧은 구간의 해당 단계 측정이며 전체 YOLO 처리량이나 경기 전체의 개선율을 뜻하지 않는다.

로컬 Next 빌드는 설치된 SWC 바이너리가 현재 macOS 런타임과 맞지 않아 실행할 수 없었다. 공개 JS 구문 검사·에디터 번들은 통과했다. 프로덕션 Linux 이미지 빌드로 최종 웹 빌드를 검증한다.
