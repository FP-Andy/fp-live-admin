# 풋살 개인 매치 리포트 자동 멘트 설계

2026-09-30. 이번 배포는 A4 PDF·로고·영상 재생 개선이며, 아래 자동 생성 확장은 다음 구현 범위다.

## 현재 코드에서 확인한 상태

- FCM 매치 리포트는 영상 기록과 같은 `/futsal/fla-video/fixtures`의 39경기를 선택한다.
- 히트맵은 FPA에서 전달하거나 JSON으로 불러온 좌표·관측 시간이다. FPA 이벤트는 선택 경기의 저장 로그를 가져온다.
- `commentDraft()`는 활동 구역, 볼 회수·슈팅 여부, 입력한 포지션으로 기본 문구를 만든다. 현재는 버튼을 눌러야 하며, 3개씩의 리뷰를 모두 채우지는 않는다.
- 초안은 브라우저 IndexedDB에 저장된다. 아직 서버에서 39경기의 검수 결과와 개인 리포트를 일괄 연결하는 저장 구조는 없다.

## 운영자가 할 일

경기 선택 → 검수 결과 버전 선택 → 선수 명단 연결 확인 → 포지션·공격 방향 보완 → 자동으로 채워진 문구 수정 → A4 PDF 다운로드.

히트맵 결과에 명시적인 경기 ID를 저장한다. 파일명은 연결 후보를 제안하는 데만 쓰며 최종 연결 근거로 쓰지 않는다. 선수는 팀·실제 선수 ID와 출전 구간으로 연결하고, 초기 인식 번호와 실제 등번호를 구분한다. 등번호만 같은 두 팀의 선수나 교체 전후 선수를 합치지 않는다.

## 각 영역의 생성 근거

| 영역 | 입력·계산 | 출력 방식 |
| --- | --- | --- |
| 경기·선수 정보 | 39경기 ID, 팀, 명단, 실제 등번호, 이름, 포지션, 확정 스코어 | 자동 채움. 미완료 경기의 기본 0:0을 확정 무승부로 쓰지 않음 |
| 활동 이야기 | 방향 보정한 시간 가중 구역 비중, 평균 위치, 유효 관측 시간, 충분히 관측된 초반·후반 비교 | 주요 활동 공간과 변화 2~3문장. 위치만으로 수비 성공·공격 기여를 판정하지 않음 |
| 플레이 이야기 | 선수에 연결된 FPA 볼 회수·슈팅 위치, 결과·골 태그, 검증된 키패스·도움 태그 | 실제로 기록된 행동과 공간을 설명. 기록 0건은 미기록과 무활동을 구분 |
| 좋았던 장면 3개 | 서로 다른 위치·이벤트 근거를 우선순위로 선정 | 같은 사실을 표현만 바꿔 반복하지 않음. 근거가 부족한 항목은 추가 확인 상태 |
| 다음 경기를 위한 제안 3개 | 관측 특징 + 등록 포지션·전술 메모 | 부드러운 제안·확인할 장면. 기록되지 않은 실수나 약점을 만들어내지 않음 |

FLA 점유율·공격 방향은 팀 경기 맥락에만 사용한다. 선수 식별이 없는 팀 슈팅이나 팀 수치를 개인의 성과로 배분하지 않는다. FPA와 FLA가 동일 슈팅을 기록했을 때 두 번 합산하지 않으며, 개인 이벤트의 기본 원천은 FPA로 정한다.

## 자동 생성과 수정 보존

1. 검수 버전이 고정된 좌표와 이벤트를 먼저 집계한다. 프레임 수 대신 관측 시간을 가중한다. 교체 정보가 있으면 실제 출전 구간으로 관측률을 계산하고, 없으면 분석 구간 관측률임을 표시한다.
2. 집계 결과를 근거 항목으로 저장한다. 각 항목에는 경기·선수 ID, 결과 버전, 구간, 관측량, 이벤트 ID가 포함된다.
3. 데이터 연결 시 모든 선수의 비어 있는 문구를 자동 생성한다. 포지션·방향·검수 버전이 바뀌면 해당 근거와 자동 문구만 갱신한다.
4. 문구마다 `자동 생성 / 직접 수정 / 갱신 가능` 상태와 입력 지문을 저장한다. 직접 고친 문구는 유지하고, 새 초안과 비교해서 선택적으로 교체한다. 수동으로 비워 둔 칸도 수동 수정으로 취급한다.
5. 기본은 근거 기반 규칙 문장으로 즉시 생성한다. 향후 언어 모델은 구조화된 근거와 운영자가 입력한 메모를 자연스럽게 다듬는 역할만 맡긴다. 생성 실패 시 기본 문구를 유지한다.
6. A4 분량을 문단별로 제한한다. 활동·플레이 이야기 각 2~3문장, 리뷰 각 1문장으로 만들고, 최종 DOM 넘침 검사도 유지한다. 저장에는 원문과 근거를 보존한다.

## 품질 기준과 확인 방법

- 한쪽 구역 비중이 거의 같으면 특정 구역에 집중했다고 단정하지 않는다. 관측량이 부족한 시간대는 전후 비교를 생략한다.
- 다른 팀·선수 혼입, 출전하지 않은 구간, 좌표 없는 이벤트를 별도 집계한다. 불확실한 데이터로 단정하는 문장은 만들지 않는다.
- 모든 해석 문장을 근거 ID로 역추적할 수 있게 한다. 승패 비판, 수비 능력·전술 의도·체력 저하 같은 검증되지 않은 평가는 생성하지 않는다.
- 39경기에서 고관측·저관측·교체·이벤트 없음·유니폼 혼동 사례를 골라 운영자 문구와 비교한다.
- 확인할 지표: 근거 없는 문장 수, 선수 연결 오류, 사람 수정률, 리포트당 작업 시간, A4 넘침 비율. 희망 수치를 성능으로 보고하지 않는다.

## 구현 순서

1. 명시적 경기/선수 연결과 출처 저장 → 자동 빈칸 채움·수정 잠금 → 관측량을 고려한 활동·이벤트 초안.
2. 긍정 장면·제안 후보 순위화 → 근거 보기·개별 재생성 → 선수 전체 일괄 생성.
3. 서버 초안/버전 저장과 검수 결과 자동 선택 → 필요하면 언어 모델 문장 다듬기.
