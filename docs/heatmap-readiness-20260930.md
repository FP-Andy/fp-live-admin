# 39경기 히트맵 준비 상태 · 2026-09-30

운영 API DB와 GPU 작업 목록을 읽기 전용으로 대조했다. 39개 FLA 경기 중 **38경기는 연결된 영상의 분석 완료 결과가 있다. 경남–대구 1경기는 영상 연결 미확정**으로 집계하지 않았다. 이름이 없는 기존 DJI 영상을 임의 매칭하지 않았다. 실행 중/대기 작업은 모두 0개였다. 38건 모두 초기 연결 수는 13명으로 기록되어 있다.

서버 검수 저장본은 6경기, 추가 검수 반영 이력은 울산–전북·광주–경남·수원FC–대전 3경기다. 수원FC–대전에는 아직 반영하지 않은 구간 수정이 있다. 서버 저장 횟수를 검수 차수로 해석하지 않았다.

## 이번에 전체 구간 재계산한 세 경기

배포된 `identity-v5-initial-recovery-1` 코드의 초기 설정 복구, 마지막 적용 입력, 재연결과 히트맵 필터를 그대로 사용했다. 기본 UI 설정인 BB 하단 좌표, 기본 코트 방향, 자동 연결 포함이다. 관측률의 분모는 초기 설정 이후 분석 구간 전체 시간이며 골키퍼·심판을 제외한 필드 선수 10명 평균이다.

**38경기 전체의 최신 유효 관측률 평균은 이번에 계산하지 않았다.** 기존 코드에서는 완료 목록에 품질 요약을 저장하지 않아 매번 전체 선수 연결 계산이 필요하다. 장시간 전수 재계산 대신 위 3경기의 최신 수치를 확인한 단계다. 과거 초벌 수치를 최신 검수 결과로 섞지 않았다.

광주–경남은 최종 번호 대조와 교체 확인 후 개인 리포트 원본으로 확정할 후보이다. 울산–전북은 선수별 판단이 필요하며 관측이 낮고 공백이 긴 선수는 추가 검수가 필요하다. 부천–충남아산 초벌로 경기 전체 개인 히트맵을 제공하는 것은 권하지 않는다. 세 경기만으로 나머지 경기의 수치를 추정하지 않는다.

유효 관측률은 선수 신원 정답률이 아니다. 이번에는 독립된 영상 정답 대조를 수행하지 않았다. 교체 전후 출전 시간도 분모에 반영되지 않아, 긴 공백에는 교체·화면 이탈·미연결이 함께 포함될 수 있다. 따라서 39경기를 그대로 일괄 제공할 단계로 판단하지 않는다.
